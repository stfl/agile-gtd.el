#+title: org-ql predicates

The org-ql predicates agile-gtd defines for its core concepts, for use in
your own queries. Back to the [[file:../README.org][README]].

The package exposes org-ql predicates for the workflow's core concepts:

| Predicate                   | Meaning                                                                                                                                        |
|-----------------------------+------------------------------------------------------------------------------------------------------------------------------------------------|
| =agile-gtd-stuck=           | project or epic with no open PROJ/EPIC/NEXT/WAIT child (alias =agile-gtd-stuck-proj=)                                                          |
| =agile-gtd-standalone-next= | NEXT/WAIT without a project ancestor                                                                                                           |
| =agile-gtd-tickler=         | deferred item with SOMEDAY + SCHEDULED                                                                                                         |
| =agile-gtd-tickler-proj=    | project wholly parked in the tickler                                                                                                           |
| =agile-gtd-someday=         | deferred item                                                                                                                                  |
| =agile-gtd-habit=           | habit by tag or Org habit style                                                                                                                |
| =agile-gtd-tangling=        | task left under a completed ancestor                                                                                                           |
| =agile-gtd-work=            | any work item                                                                                                                                  |
| =agile-gtd-private=         | non-work item                                                                                                                                  |
| =agile-gtd-blocked=         | task with an unsatisfied org-edna BLOCKER dependency                                                                                           |
| =agile-gtd-within-range=    | item ranking inside a range, such as =(agile-gtd-within-range today)=, or at or above a priority's band, such as =(agile-gtd-within-range ?C)= |
| =human-turn=                | the human's move in the agent loop (alias =agile-gtd-human-turn=)                                                                              |
| =agent-turn=                | the agent's move, of any kind or of one, such as =(agent-turn replied)= (alias =agile-gtd-agent-turn=)                                         |
| =agent-wait=                | work the agent has claimed and is doing (alias =agile-gtd-agent-wait=)                                                                         |

These predicates drive agenda commands and review views. The three turns,
and the four kinds of agent turn (=delegated=, =replied=, =answered= and
=withdrawn=), are defined in [[file:agent-loop.org::*Whose turn it is][Whose turn it is]]. A query names a turn
rather than the tags and states behind it, so it keeps its meaning however
those are read.
